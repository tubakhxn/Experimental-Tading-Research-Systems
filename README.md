# Experimental Trading Research Systems

This repository contains four experimental quantitative research systems built using synthetic data, machine learning, and statistical modeling techniques.

These projects are built for research, visualization, and educational purposes only.

---

## 1. Alpha Decay Research Engine

### Overview

Measures how trading signals lose predictive power over time.

### What it does

* Generates synthetic market data
* Studies alpha signal decay
* Creates decay visualizations
* Produces research metrics

Research & Educational Purposes Only.

Run:

```bash
python alpha_decay_research_engine.py
```

---

## 2. Cross-Asset Lead-Lag Explorer

### Overview

Explores whether one asset tends to move before another.

### What it does

* Generates synthetic assets
* Computes lead-lag relationships
* Creates heatmaps
* Visualizes asset interactions

Research & Educational Purposes Only.

Run:

```bash
python cross_asset_lead_lag_explorer.py
```

---

## 3. Correlation Breakdown Detector

### Overview

Detects periods when asset correlations become unstable.

### What it does

* Computes rolling correlations
* Identifies regime changes
* Creates correlation surfaces
* Visualizes instability

Research & Educational Purposes Only.

Run:

```bash
python correlation_breakdown_detector.py
```

---

## 4. Market Fragility Simulator

### Overview

Models how market shocks spread through connected assets.

### What it does

* Simulates market networks
* Generates liquidity shocks
* Measures contagion effects
* Creates network visualizations

Research & Educational Purposes Only.

Run:

```bash
python market_fragility_simulator.py
```
